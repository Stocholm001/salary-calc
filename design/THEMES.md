# ธีมสี — กระปุกปลดหนี้ (debt-piggy)

รหัสสีของทุกชุดในหน้า "สีทางเลือก" บนแคนวาส (ภาพ `สีทางเลือก-01-05.png`, `สีทางเลือก-06-10.png`) ชุด 00 คือสีเหลืองเดิมใน SPEC.md ข้อ 4
ทุกชุดผ่านคอนทราสต์ตัวหนังสือ ≥ 4.5:1 (ink/bg, muted/bg, muted/card-hi, on-accent/accent, accent/card, paid/card, paid/paid-bg, warn-ink/warn-bg)
ไฟล์ที่ใช้ในโค้ด: `themes.css` (CSS variables แบบ `[data-theme="…"]`) และ `themes.json`

## หน้าที่ของแต่ละ token

| token | ใช้กับ |
|---|---|
| `--bg` | พื้นหลังแอป |
| `--card` | การ์ด, ช่องกรอก, เมนูล่าง |
| `--ink` | ตัวหนังสือหลัก |
| `--muted` | ตัวหนังสือรอง, label, ไอคอนเมนูที่ไม่ได้เลือก |
| `--line` | เส้นขอบ, รางวงแหวน, รางแถบ, ราง segmented |
| `--card-hi` | การ์ดเด่น, ป้ายลำดับ 2+, ปุ่ม "ใช้ยอดเดือนก่อน" |
| `--accent` | ปุ่มหลัก, วงแหวน, ลำดับ 1, ยอดคงเหลือ, แท็บที่เลือก, หมวด "ชำระหนี้" |
| `--on-accent` | ตัวหนังสือ/ไอคอนบนพื้น --accent |
| `--paid` | ยอดจ่ายแล้ว, ก้อนที่ปิด, ป้าย "จ่ายแล้ว", หมวด "ออม/สำรอง" |
| `--bar` | หมวด "ค่าครองชีพ", แท่งกราฟเดือนอื่น |
| `--warn-bg` | พื้นป้าย "ยังไม่จ่าย", ปุ่มลบ |
| `--warn-ink` | ตัวหนังสือป้าย "ยังไม่จ่าย", ปุ่มลบ, เตือนเกิน 100% |
| `--paid-bg` | พื้นป้าย "จ่ายแล้ว" |
| `--zebra` | แถวสลับสีในตาราง |
| `--pig` / `--pig-dark` | หมูกระปุก `#FFC2D4` / `#FFA8C1` (ทุกธีมเหมือนกัน), หมวด "อื่น ๆ" ใช้ `--pig-dark` |

## หมายเหตุ
- ชุด 01 มินต์ และ 06 มัทฉะ ใช้ `--paid` เป็นน้ำเงิน เพราะสีหลักเป็นเขียว จะได้แยกยอดจ่ายแล้วออกจากปุ่มได้
- ชุด 10 กลางคืน เป็นโหมดมืด: `--on-accent` เป็นสีเข้ม (ตัวหนังสือบนปุ่มเหลืองอำพัน) และควรตั้ง `<meta name="theme-color">` เป็น `--bg`
- ตอนนี้ยังไม่ได้เลือกชุดสุดท้าย ถ้าเลือกแล้วให้แก้ค่า `:root` เป็นชุดนั้น และแก้ `theme_color` / `background_color` ใน `manifest.json` ให้ตรง
